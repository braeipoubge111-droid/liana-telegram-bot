# ربات تلگرام فروشگاه لیانا — نسخه آفلاین هوشمند

## قابلیت‌ها
- گفت‌وگوی فارسی بدون Groq یا هیچ API هوش مصنوعی؛ پاسخ‌ها از قوانین داخلی و کاتالوگ محصولات ساخته می‌شوند.
- پاسخ‌های متنوع برای سلام، احوالپرسی، تشکر و خداحافظی.
- جست‌وجوی محصولاتات با نرمال‌سازی حروف فارسی و پیدا کردن گزینه‌های مرتبط.
- پیشنهادهای اولیه برای پرسش‌هایی مانند نوع پوست، ضدآفتاب، محصولات لب و کرم‌پودر؛ هر جا اطلاعات دقیق موجود نباشد، ربات آن را شفاف می‌گوید.
- توضیح پایه برای هر ۳۸۱ محصول بر اساس نام و دسته‌بندی، بدون ساختن ادعاهای تأییدنشده درباره ترکیبات یا اثر محصول.
- منو، دسته‌بندی، عکس محصول، تنوع‌ها و استعلام قیمت/موجودی و اطلاعات فروشگاه.

## نصب
1. Python 3.10 یا بالاتر نصب کن.
2. فایل ZIP را استخراج کن.
3. در پوشه پروژه اجرا کن: `pip install -r requirements.txt`
4. `.env.example` را به `.env` تغییر نام بده.
5. توکن ربات را در `BOT_TOKEN` وارد کن.
6. اجرا: `python bot.py`

## نکته مهم
این نسخه برای پاسخ‌گویی پایه و جست‌وجوی محصولات به `GROQ_API_KEY` یا API دیگری نیاز ندارد. با این حال، این یک مدل زبانی کامل نیست؛ پاسخ‌های آن بر اساس جست‌وجو، قوانین و اطلاعات موجود ساخته می‌شوند. برای تشخیص دقیق تناژ رنگ، ترکیبات، سازگاری قطعی با پوست، یا اطلاعاتی که در کاتالوگ ثبت نشده‌اند، ربات ادعای قطعی نمی‌کند و کاربر را به صفحه محصول یا فروشگاه راهنمایی می‌کند.

قیمت‌ها و موجودی ممکن است به‌روز نباشند؛ قبل از خرید استعلام بگیرید. برای اجرای شبانه‌روزی، ربات باید روی هاست همیشه‌روشن اجرا شود.


## پایگاه دانش آرایشی (نسخه گسترش‌یافته)
- فایل `beauty_knowledge.json` شامل پرسش‌وپاسخ‌های آفلاین درباره روتین پوست، پوست چرب/خشک/حساس، ضدآفتاب، ترتیب آرایش، کرم‌پودر، پرایمر، کانسیلر، محصولات لب و چشم، پاک‌سازی، نگهداری و ایمنی لوازم آرایش است.
- پاسخ‌ها بر اساس راهنمای عمومی منابعی مانند آکادمی پوست آمریکا (AAD) و سازمان غذا و داروی آمریکا (FDA) تدوین شده‌اند؛ این فایل تشخیص یا درمان پزشکی نیست.
- ربات سؤال‌های نامرتبط را رد می‌کند، برای قیمت/موجودی از اطلاعات محصولات استفاده می‌کند و بین پیدا شدن نام یک محصول و تأیید موجودی لحظه‌ای تفاوت می‌گذارد.
- جست‌وجو عمدتاً بر اساس نام و دسته‌بندی محصولات انجام می‌شود تا توضیح عمومی کالاها باعث نتیجه‌های تصادفی نشود. ربات در گفت‌وگو به مشتری درباره فایل‌های داده یا CSV اشاره نمی‌کند و از اطلاعات آن‌ها فقط برای پاسخ طبیعی استفاده می‌کند.
- اگر موضوع یا ترکیب خاصی در پایگاه دانش نیست، ربات باید بگوید اطلاعات کافی ندارد، نه اینکه اطلاعات پزشکی یا ترکیبات را حدس بزند.
