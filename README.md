# ربات تلگرام لیانا شاپ — نسخه ارتقایافته

## تغییرات این نسخه
- یکسان‌سازی نام برند در پاسخ‌ها و منوها با «لیانا شاپ / LIYANA SHOP».
- گسترش پایگاه دانش آفلاین به بیش از ۱۰۰ موضوع و پرسش‌وپاسخ فارسی درباره پوست، آرایش، انتخاب رنگ، روش مصرف، نگهداری و ایمنی.
- در صورت تنظیم `GROQ_API_KEY`، استفاده از مدل زبانی برای پاسخ‌های محاوره‌ای و پرسش‌های پیچیده‌تر، همراه با اطلاعات مرتبط محصولات.
- بدون کلید Groq نیز پاسخ‌گویی آفلاین و جست‌وجوی کاتالوگ فعال است.
- دستورهای مدل صریحاً منع می‌کنند که به مشتری درباره فایل‌ها، دیتابیس یا روش فنی دریافت اطلاعات بگوید.
- پاسخ‌های قیمت و موجودی از اطلاعات کاتالوگ گرفته می‌شوند؛ قیمت و موجودی لحظه‌ای باید از فروشگاه تأیید شوند.
- در ویژگی‌ها، ترکیبات و رنگ‌بندی تأییدنشده، ربات نباید حدس بزند یا ادعای ساختگی مطرح کند.

## نصب و اجرا
1. Python 3.10 یا بالاتر نصب کن.
2. در پوشه پروژه اجرا کن: `pip install -r requirements.txt`
3. `.env.example` را به `.env` تغییر نام بده.
4. توکن تلگرام را در `BOT_TOKEN` قرار بده.
5. برای پاسخ‌های هوشمندتر، یک کلید معتبر Groq در `GROQ_API_KEY` وارد کن. این گزینه اختیاری است؛ بدون آن ربات در حالت آفلاین کار می‌کند.
6. اجرا: `python bot.py`

## تحقیق درباره مشخصات محصولات
کاتالوگ شامل ۳۸۱ محصول است. این نسخه از نام‌ها، دسته‌بندی‌ها، تنوع‌ها، قیمت‌های ثبت‌شده و لینک‌های محصول استفاده می‌کند و توضیح عمومی را با احتیاط می‌سازد. این به معنای تحقیق مستقل و تأییدشده درباره تک‌تک ۳۸۱ کالا نیست. برای افزودن رنگ دقیق، ترکیبات، حجم و ادعاهای سازنده باید صفحه رسمی یا بسته‌بندی هر کالا بررسی شود؛ اگر این اطلاعات در داده‌ها ثبت نشده باشد، ربات باید عدم قطعیت را بیان کند، نه اینکه چیزی بسازد.

## نکات مهم
- قیمت و موجودی موجود در کاتالوگ ممکن است از وضعیت لحظه‌ای فروشگاه عقب باشد.
- برای پاسخ بهتر به پرسش‌های عمومی و پیچیده، تنظیم `GROQ_API_KEY` توصیه می‌شود.
- توکن ربات و کلید API را با دیگران به اشتراک نگذار.
- برای اجرای شبانه‌روزی، پروژه باید روی هاست همیشه‌روشن اجرا شود.
