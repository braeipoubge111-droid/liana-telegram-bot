# ربات تلگرام لیانا — نسخه ۱۰۰۰ دانش آرایشی

## تغییرات این نسخه
- پایگاه دانش آفلاین شامل دقیقاً **۱۰۰۰ مدخل پرسش‌وپاسخ** است. موضوع‌ها مراقبت پوست، محصولات آرایشی، روش استفاده، انتخاب محصول، ایمنی، نگهداری و رفع مشکلات رایج را پوشش می‌دهند.
- توضیحات هر ۳۸۱ محصول با تکیه بر **نام دقیق محصول، دسته‌بندی و تنوع/بسته‌بندی ثبت‌شده** بازنویسی شده‌اند و برای مشتری قابل‌فهم‌ترند.
- ادعاهای اختصاصی مثل ترکیبات، SPF، شماره رنگ، حجم، ماندگاری یا اثر درمانی بدون منبع رسمی همان مدل اضافه نشده‌اند.
- یک مرجع رسمی Flormar برای راهنمای عمومی مداد ابرو استفاده شده، اما تطابق دقیق مدل محصول کاتالوگ هنوز تأیید نشده است.
- فایل‌های کد و تنظیمات اصلی ربات از نسخه ورودی حفظ شده‌اند؛ فایل‌های داده به‌روزرسانی شده‌اند.

## محدودیت مهم درباره تحقیق محصول
صفحات موجود در کاتالوگ بیشتر لینک جست‌وجوی فروشگاه‌اند تا صفحه اختصاصی سازنده. بنابراین برای بسیاری از ۳۸۱ محصول، صفحه رسمی قابل تطبیق از طریق اطلاعات موجود پیدا/تأیید نشد. در چنین مواردی متن‌ها کاربرد معمول دسته محصول را توضیح می‌دهند، نه ادعای تأییدشده سازنده. برای معرفی کاملاً اختصاصی هر مدل باید لینک واقعی محصول یا عکس واضح برچسب/بسته‌بندی و در صورت امکان کد مدل در دسترس باشد.

## منابع مرجع عمومی
- Flormar، راهنمای رسمی Ultra Thin Brow Pencil: https://www.flormar.com/urun/ultra-thin-brow-pencil/
- American Academy of Dermatology، راهنمای مراقبت پوست و انتخاب محصولات: https://www.aad.org/public/everyday-care/skin-care-basics
- American Academy of Dermatology، راهنمای ضدآفتاب: https://www.aad.org/public/everyday-care/sun-protection/sunscreen

## نصب و اجرا
1. از نسخه فعلی هاست پشتیبان بگیر.
2. فایل‌های ZIP را استخراج کن و تنظیمات محیطی/توکن ربات خودت را حفظ کن.
3. نصب وابستگی‌ها: `pip install -r requirements.txt`
4. توکن را در فایل تنظیمات محیطی مطابق README اصلی قرار بده.
5. اجرای ربات: `python bot.py`

## فایل‌های کلیدی
- `bot.py`: منطق ربات و جست‌وجوی آفلاین
- `products.json`: کاتالوگ ۳۸۱ محصول با توضیحات بازنویسی‌شده
- `beauty_knowledge.json`: دقیقاً ۱۰۰۰ مدخل دانش
- `research_queue.csv`: صف پژوهش محصولی موجود در نسخه اصلی

قیمت و موجودی ممکن است تغییر کنند. قبل از استقرار روی هاست، آزمون‌های محلی و چند گفت‌وگوی واقعی را اجرا کن.
