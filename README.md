# ربات تلگرام فروشگاه لیانا — نسخه آغازین

## امکانات
- منوی شیک با دکمه‌های مشاهده محصولات، موجودی و قیمت، سؤال‌های آماده، اطلاعات فروشگاه، سایت و کانال
- دکمه‌های بازگشت و خانه
- فهرست محصولات و دسته‌بندی خودکار اولیه از نام محصول
- جست‌وجوی محصول با نوشتن نام در چت
- صفحه محصول، تصویر در صورت وجود، تنوع‌های ثبت‌شده و دکمه‌های استعلام قیمت/موجودی
- استعلام قیمت و موجودی از طریق شماره‌های فروشگاه؛ بدون AI API

## شروع سریع
1. Python 3.10 یا بالاتر نصب کن.
2. این پوشه را از حالت فشرده خارج کن.
3. در پوشه پروژه اجرا کن: `pip install -r requirements.txt`
4. فایل `.env.example` را به `.env` تغییر نام بده.
5. توکن ربات را از @BotFather بگیر و در `BOT_TOKEN` قرار بده. توکن را برای هیچ‌کس ارسال نکن.
6. اجرا: `python bot.py`

برای کار شبانه‌روزی، برنامه باید روی سرور/هاست همیشه‌روشن اجرا شود.

## محدودیت مهم داده فعلی
فایل ووکامرس آدرس مستقیم محصول و برند/توضیحات تکمیلی قابل‌اتکا برای همه محصولات ندارد؛ بنابراین لینک محصول به جست‌وجوی همان نام در سایت تبدیل شده است. فایل `research_queue.csv` فهرست محصولات برای تحقیق و تأیید مشخصات سازنده است. دسته‌بندی‌ها از نام محصول به صورت اولیه ساخته شده‌اند؛ ربات ادعا نمی‌کند که نوع پوست یا کارایی دقیق هر کالا را از روی نام می‌داند.

قیمت‌ها در CSV عمدتاً در تنوع‌ها آمده‌اند و واحد/قیمت نهایی ممکن است نیاز به تأیید داشته باشد؛ برای همین ربات فعلاً قیمت را قطعی اعلام نمی‌کند و به فروشگاه ارجاع می‌دهد. موجودی فایل نیز فقط وضعیت ثبت‌شده در زمان خروجی گرفتن است.

## فایل‌ها
- `bot.py`: کد ربات
- `products.json`: کاتالوگ ۳۸۱ محصول والد و تنوع‌های همراه
- `research_queue.csv`: صف بررسی مشخصات و لینک‌های جست‌وجوی محصول
- `.env.example`: تنظیمات نمونه
