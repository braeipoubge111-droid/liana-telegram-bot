# ربات تلگرام لیانا شاپ — نسخه ارتقایافته آفلاین

## چه چیزی بهتر شده؟
- معرفی کاربردی و خواناتر برای هر ۳۸۱ محصول؛ متن هر محصول بر اساس نام، دسته‌بندی و تنوع‌های ثبت‌شده نوشته شده است.
- توضیحات محصول درباره خود کالا و کاربرد معمول آن است؛ متن معرفی مشتری را برای شناخت کاربرد محصول به «پرسیدن از فروشگاه» ارجاع نمی‌دهد.
- پایگاه دانش آفلاین از ۱۹۲ به ۲۲۷ موضوع فارسی گسترش یافته و شامل مراقبت پوست، ترکیبات رایج، ترتیب روتین، آرایش صورت و لب، چشم، ناخن، عطر، ایمنی و عیب‌یابی است.
- ربات بدون API هم از `beauty_knowledge.json` برای پاسخ عمومی و از `products.json` برای پیدا کردن محصولات استفاده می‌کند.
- متن آغاز گفت‌وگو صمیمی‌تر شده و به مشتری درباره API یا محدودیت‌های فنی توضیح نمی‌دهد.
- پرسش‌های نامرتبط با زیبایی/محصولات با یک پاسخ کوتاه و دوستانه رد می‌شوند؛ این کنترل حتی وقتی کلید مدل آنلاین تنظیم شده باشد اجرا می‌شود.
- ۴۵ پرسش‌وپاسخ کاربردی به پایگاه دانش آفلاین اضافه شده و متن‌های عمومیِ کم‌اطلاعات برای معرفی محصول با توضیح متناسب‌تر با نام کالا جایگزین می‌شوند.
- هیچ اشاره‌ای به فایل، دیتابیس یا روش فنی نگهداری اطلاعات برای مشتری نمایش داده نمی‌شود.
- از ساختن اطلاعات تأییدنشده مثل ترکیبات دقیق، حجم، شماره رنگ، SPF یا ماندگاری خودداری شده است. متن‌های محصول، معرفی کاربردی بر اساس نام و دسته‌اند؛ این نسخه ادعا نمی‌کند که مشخصات رسمی هر ۳۸۱ محصول مستقلاً تأیید شده است.

## نصب و اجرا
1. Python 3.10 یا بالاتر نصب کن.
2. در پوشه پروژه اجرا کن: `pip install -r requirements.txt`
3. `.env.example` را به `.env` تغییر نام بده.
4. توکن تلگرام را در `BOT_TOKEN` قرار بده.
5. برای پاسخ‌های زبانی پیشرفته‌تر، در صورت تمایل `GROQ_API_KEY` را تنظیم کن. پاسخ‌گویی آفلاین بدون آن فعال است.
6. اجرا: `python bot.py`

## فایل‌ها
- `bot.py`: منطق ربات و جست‌وجوی آفلاین
- `products.json`: کاتالوگ ۳۸۱ محصول با معرفی‌های کاربردی
- `beauty_knowledge.json`: پایگاه دانش آفلاین با ۲۲۷ موضوع و پرسش‌وپاسخ
- `.env.example`: نمونه تنظیمات
- `requirements.txt`: وابستگی‌ها

## نکته دقت اطلاعات
معرفی‌ها برای کمک به فهم کاربرد معمول محصول نوشته شده‌اند؛ ترکیبات، رنگ دقیق، حجم، SPF، دوام، ادعای درمانی و مناسب‌بودن قطعی برای یک نوع پوست تنها زمانی باید اعلام شوند که صفحه رسمی سازنده یا بسته‌بندی همان مدل آن را تأیید کند. قیمت و موجودی ممکن است تغییر کنند.
